# Add a Blazor Smith Chart to a Blazor Server App

Repository contains a Blazor Server sample that demonstrates how to create and configure a Syncfusion Blazor Smith Chart using Visual Studio 2022.

A Blazor Smith Chart is used to visualize the impedance of a transmission line in high-frequency circuit applications. This sample walks through populating list data, adding legends, and enabling data labels and tooltips so you can present impedance data interactively in a Blazor Server app.

**Example**: https://blazor.syncfusion.com/demos/smith-chart/default-functionalities

**Documentation**: https://blazor.syncfusion.com/documentation/smith-chart/getting-started

## Project Overview

This sample shows how to integrate the Syncfusion Smith Chart into a Blazor Server application, configure series data, and enable interactive display options such as legends, labels, and tooltips.

## Features

- Populate list-style series data for Smith Chart visualization
- Add and configure legends for clarity
- Enable data labels to show values on the chart
- Enable tooltips for interactive data inspection

## Prerequisites

- Visual Studio 2022

## How to run the project

- Checkout this project to a location on your disk.
- Open the solution file using Visual Studio 2022.
- Restore the NuGet packages by rebuilding the solution.
- Run the project.

## Usage

Run the app and navigate to the Smith Chart demo to explore sample data, legend settings, data labels, and tooltip interactions.
